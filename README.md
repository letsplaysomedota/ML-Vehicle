# Vehicle Price Prediction using Machine Learning

## Project Overview
A regression-based machine learning project to predict vehicle prices from structured dataset features such as brand, mileage, transmission type, and fuel type.

## Key Features
- Data cleaning and preprocessing
- Lasso regression and performance evaluation
- Visualization of RMSE and R² across alpha values

## Technologies Used
Python, pandas, scikit-learn, matplotlib
